# Stamp Collection

Учебный проект на C++ для работы с коллекцией почтовых марок.

Проект был разработан для практики объектно-ориентированного программирования, разделения программы на классы и работы с данными коллекции.

## Возможности

- хранение информации об элементах коллекции
- работа с отдельными объектами почтовых марок
- объединение объектов в коллекцию
- загрузка данных из CSV-файла
- разделение модели данных и основной логики программы
- проверка работы основных компонентов программы

## Технологии

- C++
- ООП
- STL
- работа с файлами
- CSV

## Структура проекта

```text
stamp-collection-cpp/
├── logic/
│   ├── CollectionSheet.cpp

├── memory/
│   ├── MemoryUtils.cpp
│   └── MemoryUtils.h
├── model/
│   ├── Item.cpp
│   ├── Item.h
│   ├── Stamp.cpp
│   └── Stamp.h
├── main.cpp
├── Tests.cpp
├── collection.csv
├── .gitignore
└── .gitlab-ci.yml
```

### model

Содержит основные классы предметной области.

`Item` используется как базовая сущность проекта, а `Stamp` описывает объект почтовой марки.

### logic

Содержит класс `CollectionSheet`, отвечающий за работу с коллекцией объектов и основную логику приложения.

### memory

Вспомогательные функции, связанные с работой программы с памятью.

### Tests.cpp

Содержит проверки основных компонентов проекта.

## Данные

Для хранения исходных данных используется файл:

```text
collection.csv
```

Программа считывает информацию из файла и использует её при работе с коллекцией.

## Сборка

Проект можно собрать с помощью компилятора `g++`.

Пример:

```bash
g++ -std=c++17 main.cpp \
logic/CollectionSheet.cpp \
memory/MemoryUtils.cpp \
model/Item.cpp \
model/Stamp.cpp \
-o stamp_collection
```

Запуск:

```bash
./stamp_collection
```
